# Supplementary Materials for Context-Aware RAG for Troubleshooting Study

This repository contains datasets, model outputs, and evaluation scripts used in the study.

## Structure

- /data
  - external_sources: collected troubleshooting data
  - evaluation_datasets: benchmark queries

- /evaluation
  - bertscore: scripts and results
  - context awareness evaluation

- /human_evaluation
  - Human_Evaluation.xlsx
    
- /models
  - baseline_outputs_codes
  - proposed_system_outputs
  - rag_variants

## Reproducibility

All experiments can be reproduced using the provided datasets and scripts.
