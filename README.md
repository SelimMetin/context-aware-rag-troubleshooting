# Context-Aware Retrieval-Augmented Generation for Technical Troubleshooting

This repository contains the supplementary materials for the study:

**"Context-Aware Retrieval-Augmented Generation for Technical Troubleshooting: A Multilingual Architecture and Evaluation Framework "**

The repository includes datasets, model outputs, evaluation scripts, and human evaluation data used in the paper.

---

## Repository Structure

- /data
  - external_sources: collected troubleshooting data
  - evaluation_datasets: benchmark queries

- /evaluation
  - bertscore: scripts and results
  - context awareness evaluation

- /human_evaluation
  - Human_Evaluation.xlsx
    
- /models
  - baseline_outputs_codes
  - proposed_system_outputs
  - rag_variants

---

## Data

### External Sources
The `/data/external_sources` directory contains the knowledge sources used for retrieval, including publicly available troubleshooting content.

### Evaluation Datasets
The `/data/evaluation_datasets` directory contains benchmark queries used in the evaluation, including:
- error-code queries
- known-issue queries
- general troubleshooting queries

---

## Model Outputs

The `/models` directory contains responses generated by all evaluated systems:

- **proposed_system_outputs**: outputs of the context-aware RAG system together with baseline outputs  
- **baseline_outputs_codes**: scripts and outputs from standalone LLM baselines  
- **rag_variants**: proposed RAG and ablated RAG configurations  

---

## Evaluation

### Retrieval and End-to-End Evaluation
Context awareness evaluation scripts and required input files are provided in `/evaluation/context awareness evaluation`. (Full list of ACTION,OS, GPU, NET, RAM WORDs are given in script. )

### BERTScore Analysis
BERTScore scripts and results are located in `/evaluation/bertscore`.

> Note: BERTScore is used to measure semantic similarity between system outputs and reference answers. It is not intended as a direct measure of correctness.

---

## Human Evaluation

The `/human_evaluation` directory contains the human evaluation data used in the study.

The file `Human_Evaluation.xlsx` includes:
- annotator decisions (A / B / Tie)  
- pairwise comparisons between systems  
- reason labels (contextual fit, actionability, grounding, technical correctness)  
- aggregated results used in the paper  

The evaluation follows a blinded pairwise comparison protocol with multiple annotators.

---

## Reproducibility

To reproduce the main results of the study:

1. Load evaluation datasets from `/data/evaluation_datasets`  
2. Use external sources from `/data/external_sources`  
3. Generate responses using the proposed system and baseline configurations  
4. Run evaluation scripts from `/evaluation/`  
5. Compute BERTScore using `/evaluation/bertscore`  
6. Analyze human evaluation results from `/human_evaluation`  

All configurations used in the paper are included in this repository.
